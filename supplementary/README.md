# Exploratory search materials

These scripts and recorded outputs are preserved from the original investigation. See [finite/search-notes.md](../finite/search-notes.md) for the scope of the bounded finite search. Not every exploratory hit has a stored exact certificate, and this is not an exhaustive enumeration or a minimality proof. The two final witnesses have exact reproducible certificates in `finite/verify.py` and the 19-vertex witness has a separate Lean and rank-subset certificate. The exploratory scripts may use floating point for screening; they are not proof certificates.
